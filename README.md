# ✊✋✌️ Rock Paper Scissors Game

A fun and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. Play against the computer and test your luck while enjoying a clean and responsive user interface.

## 🚀 Live Demo

🌐 https://aakritijaiswal-collab.github.io/RockPaperScissors-React/

## 📂 GitHub Repository

🔗 https://github.com/aakritijaiswal-collab/RockPaperScissors-React

## ✨ Features

- 🎮 Play against the computer
- 🤖 Random computer moves
- 🏆 Instant win, lose, or draw result
- 📊 Live score tracking
- 🔄 Play multiple rounds
- 📱 Responsive design for different screen sizes
- 🎨 Simple and attractive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
